# 暗影演算 · 魔兽无限盗贼连招模拟器

离线、独立运行的连招计算工具，不读取游戏、不向游戏发送操作。

## 打开

公网版：[暗影演算 · 盗贼连招模拟器](https://shadowcraft-rogue-simulator.lajidui0552196.chatgpt.site)。公网版和本地版的浏览器数据各自保存，分享链接不会分享你的配置。

双击 `打开盗贼连招模拟器.vbs`，在默认浏览器使用；也可直接打开 `index.html`。无需联网、服务端或安装依赖。浏览器本地保存当前配置；清理浏览器站点数据可能丢失。切换浏览器时配置不一定共享。

## 使用

1. 在顶部三系天赋树用 ＋ / − 加点；每个天赋显示对应图标，点击图标查看当前和下一级效果、前置条件、主动技能的消耗与冷却，也可展开全部等级；也可以粘贴 wowhandbook 天赋链接，或点击“载入你的方案”导入 28 / 0 / 23。支持总计最多 51 点、层级和前置天赋校验。加点自动应用已建模效果；只做加点、尚未计入推演的天赋标为“仅加点”。原有设置会保留，直到首次改变或应用天赋。
2. 左侧填写初始能量、连续回能速度、公共 CD、基础暴击率（不含恶意）及潜行、战斗状态。天赋相关参数可手动微调；树与手动设定不一致时可重新应用天赋。装备和其他加成可自行计入基础数值。
2. 技能按钮显示追加到当前队列后单次推演的预计消耗；随机触发可能影响后续结果。点击技能加入队列，用 ↑ ↓ 调整顺序；选“等待”来计算有意留出的时间。逐行勾选“不占公共CD”可模拟不触发公共冷却的情况，具体技能以游戏内实测为准。
3. 查看每一步消耗前后能量、连击点、控制结束时刻及结果；能量不足与可反制空档等风险显示为红色，连击点超过 5 点上限时以橙色显示溢出数量；等待回能显示为普通文字，暴击及天赋触发成功显示为绿色；“累计控制空档”计算第一步到最后一步之间目标没有受到模型内控制的时间。
4. 点击“计算全部概率”，统计无缝衔接概率、各步能量不足或出现控制空档的概率。调整天赋、技能队列或阈值后需要重新点击计算。
5. 选择技能即可修改它的基础消耗、回能、冷却、控制时长和递减组；基础消耗应填写尚未扣除天赋及被动减免的数值，避免重复减免；恢复默认不会恢复其他设置。概率天赋可以分别选“按概率随机”“假设触发”或“假设未触发”；按“重新掷骰”查看另一条可能路径，必定触发的情况不会被“假设未触发”覆盖。

默认示例仅作为演示，并非推荐连招。能量不足时默认等待至足够，但冷却、潜行和连击点不满足时停止在该步骤。关闭自动等待后能量不足也会停止。所有技能在起手时假设已冷却；潜行和战斗状态由左侧设置。“确认脱战”是手动插入的假设，并不表示消失必定脱战。应用天赋树后，校验已建模的部分主动天赋技能；角色等级、装备和其他学习条件不校验。

## 起手星数和终结技天赋

- 偷袭基础 2 星，伏击、绞喉基础各 1 星；先发制人 1 / 2 / 3 级分别以 33% / 67% / 100% 几率额外获得 1 星，满级时分别是 3 / 2 / 2 星。
- 强化破甲 1 / 2 级分别减少破甲 5 / 10 点能量，仅消耗 5 星时分别返还 1 / 2 星；返星可与无情触发叠加。
- 无情按所选等级提供 20% / 40% / 60% 概率返还 1 星。无情打击按每个消耗的连击点提供 4% 至 20% 概率，模型将每星概率相加并限制在 100%，单次最多恢复 25 点且不超过能量上限。每星概率相加是当前模拟假设，请以游戏内实际机制核对。
- 破甲、刺骨、割裂、切割和肾击均可触发上述终结技天赋；割裂和切割只模拟终结技消耗、星数与天赋触发，不模拟伤害、流血或攻速。
- 封印命运 1 / 2 / 3 级分别在合格技能暴击时以 33% / 66% / 100% 几率额外加 1 星。输入不含以下天赋加成的基础暴击率；强化伏击和穿刺之伤会为相应技能增加暴击率。毁伤假设双手独立且暴击率相同，至少一手暴击时才有机会触发封印命运，单次最多触发一次。靴中剑对刺击的加星是否能触发封印命运未确认，模型不对刺击套用封印命运。
- 靴中剑 1 至 5 级使刺击分别有 20% 至 100% 的几率获得 2 星；刃光乍现提高刺击回能并缩短其冷却。穿刺之伤另有背刺概率加星。高效打击减少邪恶攻击和出血的消耗，邪恶计谋减少致盲消耗；刺骨的减耗可手动填写，兼容不同版本数据。
- 毁伤基础消耗 60 能量、获得 2 星，需勾选已学习；武器要求不自动校验。冲动按 15 秒内自然回能翻倍；冷血使下一个符合条件的技能暴击率增加 100%。天赋树中的精力每级增加 5 点上限，应用或取消加点时按差值调整；若起始能量为满值，会同步调整到新上限。
- 这是手动编排固定队列的推演工具，不会根据触发结果自动选择下一技能或搜索最优循环，天赋树会校验点数和前置条件。尚未模拟所有天赋、对手攻击或招架/闪避事件（例如调整），请不要将未列出的天赋视为已计算。

- 预谋在所选目标上增加 2 星，20 秒内未继续获得或消耗连击点则过期；默认不占公共 CD。伺机待发重置其他技能冷却。强化凿击每级增加 0.5 秒控制，飘忽不定每级缩短消失与致盲冷却 45 秒。死亡印记只模拟资源与终结技触发，不模拟伤害。
- `已计算` 仅指与本工具所计算的资源、控制或冷却相关的效果；伤害以及敌人的攻击事件不计算，未建模天赋（如调整）即使加点也不会改变结果。

## 概率分析的含义

无缝的默认定义：整条队列执行完成、没有因能量不足而等待，并且累计控制空档为 0 秒。左侧“允许累计控制空档”可调；主动插入的等待允许存在，但若它导致控制空档超限则判为不无缝。即使启用“能量不足自动等待”并最终完成，出现过能量不足仍不算无缝。各步分别统计该动作之前出现空档或能量不足的概率；统计从第一个非自身增益动作到队列结束；不是敌人实际反制成功的概率。只统计模型中已考虑的触发和控制，默认命中，且无法预测敌人实际反应。

按实际概率枚举触发分支，忽略单次推演中的“假设触发 / 未触发”；所有报告的步骤概率是占全部结果的比例；停止执行后的步骤不会被继续推算，各类问题和各步骤可能同时发生，不应相加。终点能量范围与均值包含提前中断的结果。达到 4096 条结果或计算上限后，自动改用 5000 次随机抽样估计并清楚标注；抽样值有波动，不是完整遍历。重新掷骰会更换随机种子。无情打击每星概率累加、毁伤双手暴击独立等均为模型假设，具体服务器细节有待游戏内验证。

## PvP 递减和限制

默认将偷袭/肾击设为同一昏迷组，凿击和致盲分为两个组，同组按第 1 次 100%、第 2 次 50%、第 3 次 25%、第 4 次免疫，控制结束后 18 秒重置。**这些是可调模拟假设，不是经确认的无限服官方规则。** 设置中可改比例和重置时间，技能数值区可调整控制分组；关闭递减则不计算递减。控制覆盖时剩余时长不会累加。肾击按 2 级技能，每连击点 + 1 秒计算，控制时长一栏对肾击不生效。

未模拟伤害、目标血量、攻击距离和方位、命中/闪避/招架、抗性、反制技能、对手饰品、毒药及持续伤害。凿击和致盲受伤打破的情况只模拟已建模的直接攻击，未检测自动攻击和持续伤害。鬼魅攻击后的伏击/绞喉按 7 秒免潜行窗口处理，无法验证你的武器或游戏客户端版本。`蓄势待发`在模型中按施放消耗能量技能时是否脱战且满能量判断，潜行本身不是被动的触发条件；沉着额外减耗按所选等级计算。界面的消耗对照及逐行动作显示具体减耗。实战细节以游戏内技能说明和测试为准。

## 开发验证

`node test-talent-details.js` 验证全部图标和各级说明；`node test-talents.js` 验证链接导入、天赋约束、同步和预谋；`node test-probability.js` 验证概率枚举、抽样降级、联合概率与相关天赋；`node test-engine.js` 验证回能、减耗、起手星数、天赋返星和概率分支、控制递减与重置、空档、公共 CD、能量等待、冷却、潜行及打破控制。`test-ui.js` 是界面交互验证脚本，需要注入临时副本执行；正常页面不会加载它。
